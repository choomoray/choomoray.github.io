# 快捷操作

## 快捷键

| 操作           | 快捷键                | 操作         | 快捷键            |
| :------------- | :-------------------- | :----------- | :---------------- |
| **快速填充**   | Ctrl + E              | **快速分析** | Ctrl + Q          |
| 快速跳转至一端 | Ctrl + 方向键         | 连续选中     | Shift + 方向键    |
| 快速连续选中   | Ctrl + Shift + 方向键 | 原位填充     | Ctrl + Enter      |
| 输入当前日期   | Ctrl + ；             | 输入当前时间 | Ctrl + Shift + ； |



## 快速填充

在**连续**的单元格内，使用 `Ctrl + E` 或在 **数据选项卡**中的**快速填充** 可以进行数据相似操作的快速填充，如
| 姓名   | 身份证号码         | 身份证尾数 | 姓名+出生日期   |
| :----- | :----------------- | :--------- | :-------------- |
| 平梦秋 | 530121198207183746 | 3746       | 平梦秋 19820718 |
| 何健柏 | 410482198209279874 | 9874       | 何健柏 19820927 |
| 魏曼珠 | 530121198105253328 | 3328       | 魏曼珠 19810525 |



## 快速分析

选中需要快速分析的数据，右下角或是 Ctrl + Q 选择分析样式

# 数据录入

录入快捷键：Shift + Tab / Enter，横向录入使用（Shift +）Tab 左右移动光标，一行录入完毕后，使用Enter快速回到下一行的最开始录入的位置，（Shift +） Enter 可以上下移动光标。



## 日期

**标准格式：2026-10-29 或 2016/10/29**

使用快捷键 `Ctrl + ;`快速输入当前日期

使用快捷键 `Ctrl + Shift + ;` 快速输入当前时间

使用函数 `=now()` 快速输入当前日期+时间



## 百分比

0.1 即 10%



## 分数

在分数前输入一个0空格：`0 1/5` = 1/5



## 文本

像身份证这种超长文本（Excel最多支持15位），只能使用文本来完整存储数字

在输入时前面加上单冒号+空格：`’ 123456789012345678` = 123456789012345678



## 原位填充

选中任意区域，在输入后使用 `Ctrl + Enter` 快捷键进行原位填充

|          | 原位填充 |          |          |
