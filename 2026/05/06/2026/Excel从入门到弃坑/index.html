快速分析

选中需要快速分析的数据，右下角或是 Ctrl + Q 选择分析样式

数据录入

录入快捷键：Shift + Tab / Enter，横向录入使用（Shift +）Tab 左右移动光标，一行录入完毕后，使用Enter快速回到下一行的最开始录入的位置，（Shift +） Enter 可以上下移动光标。

日期

标准格式：2026-10-29 或 2016/10/29

使用快捷键 Ctrl + ;快速输入当前日期

使用快捷键 Ctrl + Shift + ; 快速输入当前时间

使用函数 =now() 快速输入当前日期+时间

百分比

0.1 即 10%

分数

在分数前输入一个0空格：0 1/5 = 1/5

文本

像身份证这种超长文本（Excel最多支持15位），只能使用文本来完整存储数字

在输入时前面加上单冒号+空格：’ 123456789012345678 = 123456789012345678

原位填充

选中任意区域，在输入后使用 Ctrl + Enter 快捷键进行原位填充
